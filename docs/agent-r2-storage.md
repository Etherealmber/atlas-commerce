# Atlas Agent R2 conversation storage

The web Agent stores encrypted conversation snapshots in the `IMAGES` R2 binding, under `agent/<user>/<thread>.agent`. The Worker also stores an encrypted compact model-context transcript under `agent-chats/v2/<user>/<thread>.conv`. These are separate objects, not a transactional pair; the snapshot is the source for the web history UI. Existing transcript-only files are not automatically imported into that UI. The demo uses an isolated, sandbox-prefixed R2 view.

Configure a stable `AGENT_CHAT_SECRET` as a Worker secret (never commit it). Both formats use it preferentially. Older objects may use earlier configured secrets; keep those secrets available until migration is complete. Removing or rotating an old secret without re-encrypting data can make history unreadable. R2 bindings, secrets, deployed version and read-back must be verified in the actual deployment; a successful local test is not cloud verification. Existing retention/purge policies still apply.

The UI keeps a browser-local copy for interruptions, shows a storage warning on failure, and retries explicitly. A versioned R2 write prevents the updated web client from overwriting another version; a conflict retains the local edit and offers to save a separate copy. Older clients that do not send a version retain the legacy unconditional-write behavior, so update all clients before relying on cross-device conflict protection. An interruption before the 500 ms save starts can leave an edit only on that browser until the conversation is reopened. Clearing browser storage then loses an unsynced edit. A thread exceeding 500 messages or 1.5 MB is rejected rather than silently truncated.

History discovery scans at most 1,000 R2 objects and returns at most 40 recent conversations. This is not an unlimited archive. Reading, writing and listing require the authenticated user; the API signals unavailable storage or undecryptable objects rather than silently treating them as empty. Do not use D1 or plaintext KV as a fallback for new conversations.
